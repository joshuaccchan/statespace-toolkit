## Notes

- **Data read with `xlsread` and a range argument**: `chan2018_er_spectest` (`main_UCSV.m`)
  and `chan_clark_koop2018_jmcb_trendie` (`main_estimation.m`, `main_forecasting.m`).
  Equivalence tests that run these scripts cannot run on a hosted runner, which has no Excel.
- **Git LFS decision**: not used. The largest file is 296 KB
  (`chan_koop_potter2013_jbes_trendbound/legacy/ARtrendbound/Chan-Koop-Potter-2013.pdf`, the
  September 2012 working paper), and the fourteen archives total 2.2 MB.
