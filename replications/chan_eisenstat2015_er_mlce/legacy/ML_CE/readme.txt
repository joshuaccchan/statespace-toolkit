This zip file contains matlab code for computing the marginal likelihoods
for 6 models (probit, logit, t-link, VAR, dynamic factor-VAR and TVP-VAR) 
using the cross-entropy method.

This code is free to use. When you use the code in your research,
please cite:

See Chan, J.C.C. and Eisenstat, E. (2015). "Marginal Likelihood Estimation
with the Cross-Entropy Method," Econometric Reviews, 34(3), 256-285.

The main m-files are:

probit  - probit_mc.m
logit   - logit_mc.m
t-link  - bin_t_mc.m
VAR     - VAR_mc.m
TVP-VAR - TVPVAR_mc.m
DF-VAR  - DFVAR_mc.m
