This zip file contains matlab code for estimating the AR-trend-bound 
model in Chan, Koop and Potter (2013). The m-files implement the sparse precision
sampler in Chan and Strachan (2012). 

This code is free to use. When you use the code in your research,
please cite:

Chan, J.C.C., Koop, G. and Potter, S.M. (2013). A New Model of Trend Inflation,
Journal of Business and Economic Statistics, 31(1), 94-106.
