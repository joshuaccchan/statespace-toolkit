# Example Data

| File | Contents | Source |
|---|---|---|
| `FRED-MD.csv` | The FRED-MD monthly panel, March 1959-November 2025: 126 US series, each transformed to stationarity as McCracken and Ng (2016) recommend, with the date in the first column as year + month/12. ex06 drops the series with missing values, leaving 92, puts industrial production (`INDPRO`) first and standardizes each series | FRED-MD, the vintage used in the book, whose `chapter11/FRED-MD.csv` has the same content; the file of the chan-jeliazkov-2009 repository at commit `84c9fac`, where `DFM.m` reads it |
| `USCPI.csv` | US CPI inflation, monthly, 1948M1-2024M12: 1200 times the log change in the consumer price index (column `CPIAUCSL`). ex01 reads rows 2-865, 1948M1-2019M12, as `UC.m` does | FRED series CPIAUCSL; the file of the chan-jeliazkov-2009 repository at commit `84c9fac`, where `UC.m` reads it |
| `USCPI_quarterly.csv` | US CPI inflation, quarterly, 1948Q1-2025Q3: the quarterly average of the monthly index (column `CPIAUCSL`) and 400 times its log change (column `inflation`), the definition of Chan (2017). It stops at 2025Q3 because FRED has no value for October 2025. ex09 and the unobserved components tutorial read the inflation column | FRED series CPIAUCSL, fetched 19 September 2026; recent seasonally adjusted values are revised, so a later fetch can differ |
| `USCPI10_SPF.csv` | The median 10-year-ahead CPI inflation forecast of the Survey of Professional Forecasters, quarterly, 1991Q4-2026Q3, percent per year (column `CPI10`); earlier quarters have no value. The unobserved components tutorial reads it, from 1991Q4 to 2025Q3, as the long-run expectation of the model of Chan, Clark and Koop (2018) | Federal Reserve Bank of Philadelphia, `median_cpi10_level.xlsx`, sheet `Median_Level`, fetched 22 September 2026 |
| `USGDP.csv` | US real GDP, quarterly, 1947Q1-2024Q4, billions of chained 2017 dollars (column `GDPC1`). ex04 reads rows 2-293, 1947Q1-2019Q4, and takes 100 times the log, as `UC_output_gap.m` does | FRED series GDPC1; the file of the bayesian-macroeconometrics repository at commit `1e16335`, where `chapter09/UC_output_gap.m` reads it |
| `USPCE_OutputGap.csv` | US PCE inflation, quarterly, 1960Q1-2024Q4: 400 times the log change in the PCE price index (column `PCECTPI`), with the output gap for 1960Q1-2019Q4 (column `Output Gap`), estimated by the unobserved components model of the book's Section 9.1.3, the model of ex04. ex02 reads the inflation column, rows 2-261; ex03 reads both columns, rows 2-241, 1960Q1-2019Q4, as `linreg_tvp.m` does | FRED series PCECTPI, and the book's Section 9.1.3 for the output gap; the file of the chan-jeliazkov-2009 repository at commit `84c9fac`, where `linreg_tvp.m` reads it |
| `silver.csv` | Daily returns on the silver spot price, January 2005-December 2012, in percent: 2,086 values in one column, without dates. ex08 reads all of them | The file `SV/silver.csv` of the Chan and Hsiao (2014) package, archived byte for byte in `replications/chan_hsiao2014_wiley_sv`; the paper names no further source |
