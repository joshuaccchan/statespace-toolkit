# Example Data

| File | Contents | Source |
|---|---|---|
| `FRED-MD.csv` | The FRED-MD monthly panel, March 1959-November 2025: 126 US series, each transformed to stationarity as McCracken and Ng (2016) recommend, with the date in the first column as year + month/12. ex06 drops the series with missing values, leaving 92, puts industrial production (`INDPRO`) first and standardizes each series; ex05 reads `INDPRO`, `PAYEMS` and `RPI` for September 1989-December 2024 | FRED-MD, the vintage used in the book, whose `chapter11/FRED-MD.csv` has the same content; the file of the chan-jeliazkov-2009 repository at commit `84c9fac`, where `DFM.m` reads it |
| `USCPI.csv` | US CPI inflation, monthly, 1948M1-2024M12: 1200 times the log change in the consumer price index (column `CPIAUCSL`). ex01 reads rows 2-865, 1948M1-2019M12, as `UC.m` does | FRED series CPIAUCSL; the file of the chan-jeliazkov-2009 repository at commit `84c9fac`, where `UC.m` reads it |
| `USCPI_quarterly.csv` | US CPI inflation, quarterly, 1948Q1-2025Q3: the quarterly average of the monthly index (column `CPIAUCSL`) and 400 times its log change (column `inflation`), the definition of Chan (2017). It stops at 2025Q3 because FRED has no value for October 2025. ex07 reads the inflation column | FRED series CPIAUCSL, fetched 19 September 2026; recent seasonally adjusted values are revised, so a later fetch can differ |
| `USGDP.csv` | US real GDP, quarterly, 1947Q1-2024Q4, billions of chained 2017 dollars (column `GDPC1`). ex04 reads rows 2-293, 1947Q1-2019Q4, and takes 100 times the log, as `UC_output_gap.m` does; ex05 reads rows 173-313, 1989Q4-2024Q4, as quarterly growth | FRED series GDPC1; the file of the bayesian-macroeconometrics repository at commit `1e16335`, where `chapter09/UC_output_gap.m` reads it |
| `USPCE_OutputGap.csv` | US PCE inflation, quarterly, 1960Q1-2024Q4: 400 times the log change in the PCE price index (column `PCECTPI`), with the output gap for 1960Q1-2019Q4 (column `Output Gap`), estimated by the unobserved components model of the book's Section 9.1.3, the model of ex04. ex02 reads the inflation column, rows 2-261; ex03 reads both columns, rows 2-241, 1960Q1-2019Q4, as `linreg_tvp.m` does | FRED series PCECTPI, and the book's Section 9.1.3 for the output gap; the file of the chan-jeliazkov-2009 repository at commit `84c9fac`, where `linreg_tvp.m` reads it |
